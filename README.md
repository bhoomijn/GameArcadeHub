# GameArcadeHub 🎮

A curated collection of small interactive games built to practice problem-solving, logic, UI handling, and game development fundamentals using Python and JavaScript.

## Overview

This repository brings together multiple game projects into one clean, portfolio-ready gaming showcase. It demonstrates practical coding skills through simple, interactive builds ranging from terminal-based games to browser arcade gameplay.

## Why this repository matters
This project collection highlights:
- Python programming fundamentals
- JavaScript and browser-based game logic
- event-driven interactions and input handling
- score tracking, restart flows, and gameplay loops
- portfolio organization for small game projects

## Featured games
- AI Snake Game
  - browser-based snake game with score tracking and restart flow
- Mini Games Hub
  - classic Snake-Water-Gun game in Python
- Interactive Games
  - number guessing game built in Python
- Text Games
  - simple terminal-based Hangman game

## Tech stack
- Python 3
- JavaScript
- HTML5
- CSS
- Canvas API
- Terminal-based CLI games

## Quick start
### Python games
```bash
cd games/mini-games
python snake_water_gun.py
```

```bash
cd games/interactive-games
python number_guessing_game.py
```

```bash
cd games/text-games
python hangman.py
```

### Browser game
Open the following file in any browser:
```bash
games/ai-snake/index.html
```
