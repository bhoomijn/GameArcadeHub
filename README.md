# GameArcadeHub 🎮

A curated collection of small game projects and arcade-style experiments built during learning and hackathon work.

## Included games
- Mini Games Hub
  - Classic Snake-Water-Gun game in Python
- AI Snake Game
  - Browser-based snake game with score tracking and restart flow

## Repository structure
```text
GameArcadeHub/
├── README.md
├── games/
│   ├── mini-games/
│   │   ├── README.md
│   │   └── snake_water_gun.py
│   └── ai-snake/
│       ├── README.md
│       ├── index.html
│       └── script.js
└── assets/
```

## How to run
### Python game
```bash
cd games/mini-games
python snake_water_gun.py
```

### Browser game
Open `games/ai-snake/index.html` in a browser.
